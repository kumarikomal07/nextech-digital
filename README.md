# NexTech Digital — Website

Multi-page static website for NexTech Digital, a London-based technology company (est. 2018).
Plain HTML, CSS and JavaScript. No framework and no runtime dependencies.

## Run locally

```bash
npm run dev          # http://localhost:8000
```

## Editing content

Pages are generated by a small Python script, so the header, footer, cards and shared data stay consistent.

| What | Where |
|---|---|
| Services, industries, projects, tech stack, articles, contact details | `tools/data.py` |
| Header, footer, icons, cards, CTA band | `tools/ui.py` |
| Home page | `tools/pages_home.py` |
| All other pages and legal pages | `tools/pages_inner.py` |
| Styles (design tokens at the top) | `css/styles.css` |
| Interactions, animations, forms, cookie consent | `js/main.js` |

After editing anything in `tools/`, rebuild:

```bash
python3 tools/build.py   # writes the .html pages, sitemap.xml and robots.txt
```

## Pages

Home, About Us, Services (six sections with anchors), Industries (7), Our Work (filters and case-study dialogs), Technology Stack, Insights with 5 articles, Careers, Contact, Privacy Policy, Terms & Conditions, Cookie Policy, Cookie Preferences, Website Disclaimer, 404.

## Before going live

1. **Contact details** in `tools/data.py`: the domain, email, phone and WhatsApp number are placeholders. The phone uses an Ofcom drama-range number.
2. **Form endpoints** in `js/main.js` → `CONFIG`: `enquiryEndpoint`, `careersEndpoint` and `newsletterEndpoint` (for example Formspree). While empty, forms validate and show success but **send nothing**.
3. **Analytics:** set `CONFIG.gaId`. It loads only after the visitor consents.
4. **Illustrative content:** the trusted-by logos, the "50+ / 100+" figures and all projects are labelled illustrative. Replace them with real, approved content.
5. **Legal pages:** yellow "To review" boxes mark the missing company number, registered address, processors and retention periods.
6. **Team and leadership:** a placeholder note appears on About Us. Add real profiles only.
7. **Careers:** no live vacancies are shown. Add genuine roles when available.
8. **Social links** in the footer are placeholders.
9. **Office map** on Contact: add an embedded map once the address is confirmed.
